Template deployment notes

  • Host this page over HTTPS on a same-site subdomain, e.g. 202608.crckc.org.hk. It must share the crckc.org.hk site with bible.crckc.org.hk so the embedded BibleTogether page can reuse its Firebase login.
  • Keep the iframe URL’s ?embed=1; BibleTogether uses it to remove its navigation and install prompt. Do not add an iframe sandbox attribute.
  • Deploy only with your church’s existing HTTPS/DNS setup. An unrelated domain, Google Sites, or localhost creates a separate browser-storage partition and users may need to log in again.
  • This repository intentionally contains no submission endpoint. Set FORM_ACTION in the private deployed copy, or replace submitReflection() with your own approved form integration.
  • This template always displays the first day of REFERENCE_CAMPAIGN; replace that object with your campaign when deploying. Add date-selection logic only if the campaign needs it.
